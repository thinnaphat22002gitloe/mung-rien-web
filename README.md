# 🎓 มุ่งเรียน (Mung-Rien) — เว็บไซต์สื่อกลางติวเตอร์และงานสอนพิเศษ

**มุ่งเรียน (Mung-Rien)** คือแพลตฟอร์มเว็บไซต์สื่อกลางค้นหาติวเตอร์ส่วนตัวและศูนย์รวมงานสอนพิเศษสำหรับติวเตอร์และนักเรียน  
พัฒนาด้วยเทคโนโลยีเว็บมาตรฐาน (**HTML5 + Vanilla CSS + Vanilla JavaScript + SVG Icons**) รองรับการแสดงผลทุกอุปกรณ์แบบ Responsive เต็มรูปแบบ พร้อมระบบแถบนำทาง เมนูบัญชีผู้ใช้ และการสลับภาษาที่ตรงกันทุกหน้า 1:1

---

## 🌟 โครงสร้างและหน้าเว็บทั้งหมด (Website Structure)

### 👤 1. หน้าเว็บสาธารณะและสมาชิก (Public & User Pages)
*   **[index.html](index.html) (หน้าแรก)**:
    *   แถบด้านบน (Top Bar) แสดงช่องทางติดต่อ `LINE: @mungrien`, ตัวสลับภาษา `[ 🇹🇭 TH | 🇬🇧 EN ]` และเมนูดรอปดาวน์ **`บัญชี ▾`**
    *   แบนเนอร์หลัก (Hero Section) พร้อมป้ายสถานะและรูปประกอบ
    *   แถบประกาศข่าวสารวิ่ง (Announcement Marquee)
    *   แท็บคัดกรองหมวดหมู่วิชาและงานสอนยอดนิยมแบบ Interactive

*   **[student.html](student.html) (แจ้งความประสงค์ขอรับการจัดสรรติวเตอร์)**:
    *   แบบฟอร์มขอติวเตอร์แบบหลายขั้นตอน (Step Indicator)

*   **[student-done.html](student-done.html) (ส่งคำขอเรียนสำเร็จ)**:
    *   แสดงการตอบรับคำขอพร้อมไอคอนเครื่องหมายถูกสีเขียว

        *   QR Code สแกนเพิ่มเพื่อน LINE ทันที
        *   ปุ่มกดเพิ่มเพื่อน LINE Official (`@mungrien`)

    *   กล่องล็อกอินดีไซน์ **Split-Panel Modern UI**

## 🚀 วิธีการเปิดใช้งาน (How to Run)

สามารถเปิดใช้งานได้ทันทีหลายวิธี:

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รันอัตโนมัติ (บน Windows แนะนำที่สุด)
ดับเบิ้ลคลิกไฟล์ **`run.bat`** ในโฟลเดอร์นี้  
*(ระบบจะเริ่ม Web Server และเปิดเบราว์เซอร์เข้าสู่หน้าเว็บ `http://localhost:5500` ให้อัตโนมัติ)*

---

### วิธีที่ 2: เปิดผ่านเว็บเบราว์เซอร์โดยตรง (ไม่ต้องใช้เซิร์ฟเวอร์)
ดับเบิ้ลคลิกไฟล์ **`index.html`** ในโฟลเดอร์นี้ เพื่อเปิดดูผ่าน Google Chrome, Edge หรือ Safari ได้ทันที

---

### วิธีที่ 3: รันผ่าน Terminal / Command Prompt
```bash
python -m http.server 5500
```
เปิดเบราว์เซอร์ไปที่: **http://localhost:5500**

## 🔗 สถาปัตยกรรมการเชื่อมต่อ (Architecture & Backend Integration)

*   **`mung-rien-web/` (โฟลเดอร์นี้)**: ทำหน้าที่เป็น **Frontend Web Application** ที่มีอินเทอร์เฟซครบครันทุกหน้า ทุกส่วนประกอบถูกพัฒนาให้มีโครงสร้าง HTML Elements, Class, และ ID ที่สอดคล้องกับ Template ของระบบ Backend โดยตรง
*   **`../tutorbroker/`**: คือระบบหลังบ้าน **Full-Stack Production** ที่พัฒนาด้วย **Python Django + SQLite/PostgreSQL** ซึ่งรองรับฐานข้อมูล, ระบบคำนวณและวิเคราะห์รายได้, การ Export ไฟล์ Excel (.xlsx), และระบบเชื่อมต่อ LINE Messaging API
