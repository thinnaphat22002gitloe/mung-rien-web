# 🎓 มุ่งเรียน - ระบบค้นหาติวเตอร์และงานสอนพิเศษ

**มุ่งเรียน** เป็นเว็บไซต์สำหรับให้บริการค้นหาติวเตอร์ส่วนตัวและแหล่งรวมงานสอนพิเศษสำหรับติวเตอร์ พัฒนาขึ้นด้วยเทคโนโลยีเว็บพื้นฐาน (HTML5, CSS3, Vanilla JavaScript) ที่มีความยืดหยุ่นสูง ออกแบบหน้าจอให้มีความสวยงาม ทันสมัย และรองรับการแสดงผลบนทุกอุปกรณ์ (Responsive Design)

---

## 🌟 ฟีเจอร์เด่น (Key Features)

### 👤 ฝั่งผู้ใช้งานทั่วไป (Frontend Pages)
*   **หน้าแรก (Home)**: แหล่งรวมงานสอนแนะนำ พร้อมระบบแยกแท็บวิชาเพื่อความรวดเร็วในการค้นหา
*   **งานสอน (Jobs)**: ค้นหางานสอนพิเศษที่สนใจ คัดกรองตามวิชา สถานที่ และวันเวลาเรียน
*   **สำหรับนักเรียน (Student)**: ฟอร์มยื่นความต้องการขอรับติวเตอร์ส่งตรงถึงระบบหลังบ้าน
*   **สมัครติวเตอร์ (Register)**: หน้าสมัครสมาชิกสำหรับผู้ที่ต้องการหารายได้เสริมจากการสอน
*   **เว็บบอร์ด (Webboard)**: พื้นที่ถาม-ตอบ แลกเปลี่ยนข้อมูลและเทคนิคการเรียนการสอน
*   **เข้าสู่ระบบ / ลืมรหัสผ่าน**: ระบบ Authentication สำหรับผู้ใช้และแอดมิน

### 🛠️ ฝั่งแอดมิน / หลังบ้าน (Admin Backoffice)
*   **แดชบอร์ด (Dashboard)**: แสดงข้อมูลสรุป สถิติผู้ใช้งาน และรายการงานสอนล่าสุด
*   **ระบบจัดการงานสอน (Manage Jobs)**: เพิ่ม แก้ไข และลบข้อมูลงานสอนพิเศษ
*   **ระบบจัดการติวเตอร์ (Manage Tutors)**: อนุมัติสิทธิ์และจัดการโปรไฟล์ติวเตอร์
*   **ระบบจัดการผู้ใช้ (Manage Users)**: ตรวจสอบและดูแลบัญชีผู้ใช้ในระบบ
*   **ระบบจัดการหมวดหมู่ (Manage Categories)**: เพิ่มและแก้ไขหมวดหมู่วิชาเรียน
*   **ระบบจัดการเว็บบอร์ด (Manage Webboard)**: ควบคุมดูแลกระทู้และเนื้อหาที่ไม่เหมาะสม
*   **ระบบจัดการการแจ้งเตือน (Manage Notifications)**: ส่งและจัดการการแจ้งเตือนถึงผู้ใช้
*   **ระบบตั้งค่า (Settings)**: จัดการข้อมูลพื้นฐานของเว็บไซต์และข้อมูลการติดต่อ

## 🚀 วิธีการเปิดใช้งาน (How to Run)

โครงการนี้เป็นเว็บแบบ Static Frontend สามารถเปิดทำงานได้หลายวิธีดังนี้:

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์รันอัตโนมัติ (ง่ายและแนะนำที่สุด)
ในโฟลเดอร์โครงการจะมีไฟล์สำหรับรันอัตโนมัติ:
*   **สำหรับ Windows:** ดับเบิ้ลคลิกไฟล์ `run.bat`
*   *(ระบบจะเปิดเซิร์ฟเวอร์จำลองและเปิดเบราว์เซอร์เข้าสู่เว็บ `http://localhost:8000` ให้โดยอัตโนมัติ)*

### วิธีที่ 2: ดับเบิ้ลคลิกเปิดผ่านหน้าเว็บตรงๆ
*   ดับเบิ้ลคลิกไฟล์ [index.html](index.html) ในโฟลเดอร์โครงการเพื่อเปิดใช้ผ่าน Web Browser ได้ทันที

### วิธีที่ 3: รันผ่าน Live Server (ใน Trae IDE / VS Code)
1. คลิกขวาที่ไฟล์ [index.html](index.html)
2. เลือก **"Open with Live Server"** (ระบบจะรันบน `http://127.0.0.1:5500`)

### วิธีที่ 4: ใช้ Local Server ผ่าน Command Line
หากต้องการรันแบบควบคุมพอร์ตเองใน Terminal:
*   **Python:**
    ```bash
    python -m http.server 8000
    ```
*   *(หลังจากพิมพ์แล้วให้เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`)*

## 🛠️ การพัฒนาต่อยอดในอนาคต (Future Expansion)
1. **เชื่อมต่อฐานข้อมูล (Database)**: เช่น Supabase, Firebase หรือ MySQL เพื่อเก็บข้อมูลผู้ใช้และโพสต์จริง
2. **ระบบหลังบ้าน (Backend API)**: พัฒนา REST API ด้วย Node.js (Express), Python (FastAPI) หรือ PHP (Laravel) เพื่อรับส่งข้อมูลแบบ Real-time
3. **ระบบแจ้งเตือน (Notifications)**: เพิ่มการแจ้งเตือนผ่าน Line Notify หรือ Email เมื่อมีการสมัครงานสอนสำเร็จ
4. **รองรับหลายภาษา (i18n)**: ขยายระบบ `lang.js` ให้รองรับภาษาอังกฤษและภาษาอื่นๆ อย่างสมบูรณ์
